PROJECT OVERVIEW
----------------
DreamYard is a clothing store application with a React/Vite client and an
Express/Mongoose server. The browser communicates with the server over the
/API routes. The server connects to MongoDB; it also integrates with external
services for payments, image hosting, Google sign-in, and shipment tracking.

ARCHITECTURE DIAGRAM
--------------------

  Shopper / Administrator
            |
            | Browser: React app, routes, shared contexts
            v
  +--------------------------+
  | client/                  |
  | Vite development server  |
  | localhost:5173           |
  +--------------------------+
            |
            | /api/* and /uploads/*
            | Vite proxy in development
            v
  +--------------------------+
  | server/                  |
  | Express API              |
  | localhost:5000           |
  +--------------------------+
      |          |          |
      |          |          +---- Cloudinary image service
      |          +--------------- Razorpay payment service
      +-------------------------- MongoDB Atlas
      |
      +-------------------------- Ship24 tracking service
      +-------------------------- Google OAuth verification

  Client request flow:
    Page / Component -> Context or API helper -> Express route
    -> Middleware -> Controller -> Mongoose Model -> MongoDB
    -> JSON response -> Client UI

  Admin request flow:
    Admin page -> adminApi.js -> /api/admin route
    -> admin authentication middleware -> admin controller
    -> Mongoose Model -> MongoDB

ENVIRONMENT AND OMITTED FILES
-----------------------------

The actual .env files are local and contain private credentials. They are
listed by filename above, but their contents are intentionally not included.
Never commit or share real secrets. Use the .env.example files as templates.

Generated/dependency directories such as node_modules/ and client/dist/ are
not expanded in this inventory. They are created by installs/builds and are
not application source files. Runtime uploads, if present, are generated data
and are not listed here.

MAIN LOCAL COMMANDS
-------------------

  npm run dev                 Start client and server from the root
  npm run dev --prefix server Start the API only
  npm run dev --prefix client Start the Vite client only
  npm run build --prefix client Build the client for production
